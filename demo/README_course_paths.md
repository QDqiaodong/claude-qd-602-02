# 学员课程路径 · 演示说明

课程之间存在先修关系。一门课可以**要求完成全部指定课程**（ALL），也可以包含若干
**等价先修组**（ELECTIVE，同组任意完成一门即可）。课程页提供学员路径视图：
从目标课程向前解析直接与多级依赖，给出「可学 / 正在学习 / 受阻 / 已停开 / 循环依赖 / 数据缺口」
结论，并展示**仍缺少的最短先修路径**作为明确的缺口路径。

## 一、统一口径（列表 / 详情 / 单个约课 / 批量约课同一判定）

- 解析在后端整图完成（`CoursePathResolver` + `PathViewAssembler`），前端只渲染：
  课程列表、课程详情展开、刷新、单个约课、一键多科报名拿到的结论**完全一致**。
- 只有 **COMPLETED 已完成** 记录能解锁后续课程：
  | 学习记录状态 | 展示 | 是否解锁 |
  | --- | --- | --- |
  | COMPLETED | 已完成 | ✅ 唯一可解锁 |
  | LEARNING | 正在学习 | ❌ |
  | NORMAL | 正常（旧记录） | ❌ 旧选课不自动视为完成，但照常展示 |
  | CANCELED | 已退课 | ❌ |
  | NULL/非法 | 状态缺失 | ❌ 历史状态缺失照常展示、不解锁 |

## 二、最短缺口路径的择优规则

多条可行路线时，对每个先修要求（ALL 项 / ELECTIVE 组）按顺序择优：

1. **缺失课程数最少**（等价组只取选中的一门，同组缺口不重复计数；共享先修节点也不重复计数）
2. 缺失数相同 → **层级最浅**（缺口链最大深度小者优先）
3. 再相同 → **课程编号升序**

缺口路径按「深 → 浅」排列，目标课程自身不计入；深度相同按编号升序，因此结论稳定可复现。

## 三、脏数据容忍

| 脏数据 | 行为 |
| --- | --- |
| 自指（12 → 12） | 结论 CYCLE，循环路径 `C-6012 → C-6012`，遍历立即终止 |
| 环路（13 ⇄ 14） | 结论 CYCLE，给出 `C-6013 → C-6014 → C-6013` 可读路径 |
| 多级挂环（17 → 13…） | 在环处终止，不无限递归、不拖垮整页 |
| 等价组里有环成员 | 自动绕开循环成员，选健康成员（9：`[2 | 13(环)]` → 选 2） |
| 先修课已停开 | **已完成**仍可作为过去先修解锁后继（10 → 22 可学）；未完成路线不可走（4 → 24 受阻）；停开课自身不能作为新目标 |
| 依赖课程被删除 | 保留 `C-?199` 占位，路线标 DATA_GAP（16） |
| 学习记录指向已删除课程 | 学员路径包 `orphanEnrollments` 保留占位 |
| 无任何先修关系 | 默认可学 |

## 四、约课守卫（单个 / 批量共用）

- 单个约课与一键多科报名都过同一个 `guardEnroll`：结论不符即 400 中文原因，
  受阻时错误信息直接带最短缺口路径编号链，循环时带可读循环路径。
- **批量选中的课程不能在同一批里互相充当已完成先修**：守卫只读数据库既有 COMPLETED 记录，
  同批 `[8, 7, 6]` 中 6 缺 7、7 缺 8，即使都在本次提交里也一律被拦。
- 前端不做「隐藏选课按钮」式的假校验，是否可约以后端解析为准。

## 五、查询规模（常数次，不随课程数 / 深度增长）

一次查看某学员全部课程路径，后端固定执行：

1. 全部课程（1 条）
2. 全部先修关系（1 条，整图读入内存）
3. 学员名单（1 条 IN）
4. 该学员全部学习记录（1 条，不过滤状态、不内连接课程，以保留孤儿记录）

依赖解析全部在内存图上完成。自动化检查通过响应头 `X-Query-Count`（请求带 `?sqlProbe=1`）
断言：学员全量路径、空记录学员、单课路径查询次数相同且为固定常数。

## 七、自动化端到端验证

```bash
python3 demo/e2e_course_paths.py
# 自定义地址
BASE=http://127.0.0.1:8080 python3 demo/e2e_course_paths.py
```

覆盖：三层依赖、等价先修、多路线择优（缺口数/层级/编号）、停开课程、缺失关联、
旧状态不解锁、循环可解释、**列表与详情结论一致**、**单个与批量入口一致**、
**批量同批不互相解锁**、**查询规模常数稳定**（X-Query-Count）、空记录稳定、刷新一致。

后端另有纯内存单测 `CoursePathResolverTest`（18 项）与 Mockito 装配/守卫测试
`CoursePathServiceTest`（7 项），不依赖数据库。

## 八、接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/students/{id}/course-paths` | 学员全部课程路径（整图常数次查询）+ 孤儿学习记录 |
| `GET /api/students/{sid}/course-paths/{cid}` | 单门课程路径（与列表同源，详情/刷新一致） |
| `POST /api/enrollments` | 单个约课，先修守卫不满足返回 400 + 缺口路径 |
| `POST /api/enrollments/batch` | 批量约课，同一守卫；同批课程不互相解锁 |
